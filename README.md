# Плагины NEOVIDA для Codex и ChatGPT

Три плагина-отдела для предпринимателя. Внутри каждого несколько навыков: регламентов, по которым агент делает одну операцию так, как принято у вас.

| Плагин | Навыки внутри |
|---|---|
| Собственник | разбор недели, матрица делегирования, пре-мортем проекта, трудный разговор |
| Продажи | возражения, аудит воронки, позиционирование, распаковка эксперта |
| Деньги и договоры | юнит-экономика, аудит договора по праву РФ |

## Как поставить в Codex

1. Откройте приложение ChatGPT на компьютере, слева вверху выберите Codex.
2. Слева откройте «Плагины». Нажмите стрелку рядом с «+» и выберите Add marketplace.
3. Вставьте `albertvaleev230985/neovida-plugins` и нажмите Add marketplace.
4. Откройте вкладку Personal, найдите нужный плагин и нажмите Add, потом Add to Codex и Install.
5. Откройте новый чат и опишите задачу. Навык включится сам. Явный вызов: знак `$` и имя навыка, например `$weekly-review`.

## Что такое плагин

Навык это регламент одной операции, «как делать». Плагин это стартовый набор отдела одним пакетом: внутри могут быть навыки, коннекторы и команды. В этих трёх плагинах только навыки, подключений и ключей они не требуют.
